Ahora cuando inicies el monitor desde la app web (http://localhost:8080):

1. Click en "Iniciar Monitor" en la interfaz web
2. El monitor se ejecuta EN SEGUNDO PLANO
3. ✅ Aparece ICONO en la bandeja del sistema:
   
   • macOS    → Icono en la barra superior (rumps)
   • Windows  → Icono en la bandeja del sistema (pystray)
   • Linux    → Icono en la bandeja del sistema (pystray)

4. Puedes hacer click derecho en el icono para:
   - Ver estado
   - Pausar/Reanudar
   - Detener monitor
   - Abrir configuración

CÓMO PROBAR:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Inicia la aplicación web:
   
   python3 Sistema_v5/web_app/run_app.py

2. Abre tu navegador en:
   
   http://localhost:8080/dashboard

3. Click en botón "Iniciar Monitor"

4. Busca el icono del monitor en:
   
   macOS    → Barra superior (junto al reloj)
   Windows  → Bandeja del sistema (cerca del reloj)
   Linux    → Panel superior/inferior (según tu escritorio)
